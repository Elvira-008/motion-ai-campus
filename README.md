# Academy AI Demo — демоверсия

Демо объединяет три модуля:
1. **AI-помощник студента** — показывает слабые темы и предлагает термины, видео и повторный тест.
2. **Генератор практических заданий** — создаёт Junior-задачу по выбранной технологии и теме.
3. **Автозаполнение дела студента** — менеджер вводит данные один раз, система сохраняет карточку и показывает список студентов.

> Важно: это демонстрационный прототип. AI-диагностика и генерация задач работают на простых правилах/шаблонах, без подключённой LLM. Вакансии не парсятся из интернета, а данные хранятся в памяти и сбросятся после перезапуска. Для реальной версии нужны PostgreSQL, авторизация и подключение AI API.

## Запуск в PyCharm / Windows

1. Распакуйте ZIP и откройте папку `academy_ai_demo` в PyCharm.
2. Откройте Terminal в PyCharm.
3. Создайте виртуальное окружение (если ещё нет):
   ```powershell
   python -m venv .venv
   .\.venv\Scripts\activate
   ```
4. Установите зависимости:
   ```powershell
   pip install -r requirements.txt
   ```
5. Запустите сервер:
   ```powershell
   uvicorn main:app --reload
   ```
6. Откройте в браузере:
   - Сайт: http://127.0.0.1:8000
   - Swagger API: http://127.0.0.1:8000/docs

## Как показать демо на презентации

- **Студент:** выберите тему «ООП», результат 42%, нажмите «Проверить знания» — появятся слабые термины и рекомендуемые видео.
- **Преподаватель:** выберите FastAPI / Junior / REST API, нажмите «Сгенерировать задание».
- **Менеджер:** заполните имя, группу и контакты, нажмите «Создать карточку» — студент появится в таблице.
